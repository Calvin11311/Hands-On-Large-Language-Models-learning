# Hands-On Large Language Models 学习仓库

从零开始学习大语言模型（LLM）的学习笔记与代码实践仓库。

## 学习内容

- **主教材**：《Build a Large Language Model (From Scratch)》—— Sebastian Raschka
- **重点章节**：第 2~5 章
  1. Token 化与词嵌入（embedding）
  2. 因果注意力机制（causal attention）
  3. 从零拼装 GPT 模型
  4. 逐 token 生成 + 温度采样 / top-k 采样
